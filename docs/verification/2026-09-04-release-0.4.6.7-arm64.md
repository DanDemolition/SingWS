# SingWS 0.4.6.7 Apple Silicon release verification

Date: 2026-09-04 PDT

## Scope

Build and publish the Apple Silicon counterpart to the existing Intel 0.4.6.7
release without changing application behavior. The v0.4.6.7 tag and `main`
initially pointed to `9eee9fede3bdfc18ec0e3249f3b328002f2fe5c0`; the release
already contained the x86_64 DMG but no arm64 asset.

## Build and packaging

- Built on an arm64 Mac with Python 3.13.15 and matched PyQt6/Qt 6.9.1.
- Built the current `native/mpv_bridge/bridge.mm` for arm64.
- Used the known-working arm64 media runtime from the previously installed
  0.4.6.6 app because the current IINA runtime has an incompatible
  libmpv/libplacebo symbol pair.
- Set the arm bundle minimum to macOS 12.3, matching its native dependencies.
- Produced `SingWS-0.4.6.7-arm64-installer.dmg`.

## Automated verification

- Desktop suite: 994 passed, including 39 subtests.
- Native/secondary suite: 86 passed.
- Focused release-tool checks after packaging edits: 18 passed, including 8
  subtests.
- Automated tests used a scratch `SINGWS_HOME`; the live log remained at 97
  lines through the test run.

## Installed launch rehearsal

Before replacement, `/Applications/SingWS.app` 0.4.6.6 and `/Users/daniel/SingWS`
were backed up to `../local-installs/20260904-105116/`. The exact 0.4.6.7
candidate was then installed under the normal app identity and launched with
the normal profile.

The running app reported arm64, Python 3.13.15, PyQt6 6.9.1, and mpv karaoke
playback. It connected and synchronized with the configured server, initialized
the arm64 BASS background engine, and remained running. The main window,
audience output, QR artwork, ticker layer, and host controls were inspected on
screen. No new `SingWS-*.ips` report or logged Python error appeared.

## Publication

The arm64 DMG was added to the existing public v0.4.6.7 GitHub release beside
the Intel DMG. `docs/release.json` and the downloads page now advertise both
architectures with their exact checksums.

## Remaining manual coverage

A full karaoke song, KaraFun capture, audio-device switching, and a physical
external-display hot-plug rehearsal were not performed. Those remain the next
recommended operator checks before using this build at a paying show.
