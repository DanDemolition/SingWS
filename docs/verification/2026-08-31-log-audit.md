## Change

Files changed for this audit only:

- `0.2.18.1.py`: `exception_handler` checks for an actual QApplication, its
  owning GUI thread, and shutdown state before constructing a dialog. It
  independently contains report-write and optional-send errors, always calls
  Python's original exception hook, and avoids claiming an unsaved report exists.
- `test_exception_handler.py`: eight fresh-process tests use the real handler
  extracted from source with fake report/send endpoints. Test cases cover no
  application, QCoreApplication only, a background thread, shutdown, normal GUI
  reporting, a full/unwritable disk, failed report sending, and actual unhandled
  startup failure. The last case leaves QMessageBox unmocked and verifies exit
  status 1, preserving the Python error rather than aborting in Qt.
- `HANDOFF.md` and this verification note.

The old code failed the no-GUI and report-write-failure regressions before the
patch. All eight pass afterward. No live messages were sent by the tests.
