## Intel build handoff

Build on the Intel Mac from app commit `a29ac93` (or a descendant containing
only release documentation). Preserve local changes when updating that checkout.
Use its Intel Python environment and Intel media framework stack. Rebuild the
native bridge before packaging so the revised CDG shader is included:

```sh
./native/mpv_bridge/build_bridge.sh --arch x86_64
./build_singws_mac_intel.sh
```

The expected artifact is `SingWS-0.4.6.8-x86_64-installer.dmg`. Install and
launch the Intel candidate with backups, verify playback, then transfer the
installer to the release checkout. The old 0.4.6.7 Intel installer does not
contain these fixes and must not be relabeled.

Publication must include both 0.4.6.8 installers. Generate the manifest with
`SINGWS_REQUIRED_ARCHES=mac_arm64,mac_x86_64 .venv/bin/python tools/write_manifest.py 0.4.6.8`
only after both artifacts exist. Upload and verify both assets before publishing
the release and pushing the new updater manifest.
