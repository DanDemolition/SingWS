## Intel build

The operator requested a local Intel build. Rosetta successfully executes x86_64
Python and Qt on this Apple Silicon Mac. A separate `.venv-build-intel-rosetta`
contains Python 3.14 and platform-pinned macOS 12 Intel dependencies; the Intel
media stack is copied from the previous Intel installer into
`native_dual_view/Frameworks-intel-release`. The native bridge is rebuilt from
the updated source for x86_64. The Silicon bridge is preserved separately.

The build script accepts explicit interpreter and bridge paths so either
architecture can be built without swapping the default environment:

```sh
SINGWS_BUILD_PYTHON="$PWD/.venv-build-intel-rosetta/bin/python" \
SINGWS_MPV_FRAMEWORKS="$PWD/native_dual_view/Frameworks-intel-release" \
SINGWS_MPV_BRIDGE="$PWD/native_dual_view/Frameworks-intel-release/libsingws_mpv_bridge.dylib" \
arch -x86_64 /bin/bash ./build_singws_mac_intel.sh
```

The expected artifact is `SingWS-0.4.6.8-x86_64-installer.dmg`. Launch and verify
the Intel candidate under Rosetta before publication. This verifies x86_64
execution locally; physical Intel hardware rehearsal remains a separate check.
The old 0.4.6.7 Intel installer does not contain these fixes and is not relabeled.

Publication must include both 0.4.6.8 installers. Generate the manifest with
`SINGWS_REQUIRED_ARCHES=mac_arm64,mac_x86_64 .venv/bin/python tools/write_manifest.py 0.4.6.8`
only after both artifacts exist. Upload and verify both assets before publishing
the release and pushing the new updater manifest.
