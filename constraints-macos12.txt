# Verified pin set for a SINGLE Intel build that runs on macOS 12 and above.
#
# Purpose: retire the separate legacy build (setup_intel_legacy_env.sh) by
# making the normal x86_64 build macOS 12-compatible, rather than maintaining a
# second environment.
#
# Verified 2026-08-07 on this repo's tools/verify_macos_min_version.py, by
# downloading each wheel for --platform macosx_12_0_x86_64 --python-version
# 3.14, extracting it, and checking the REAL Mach-O load commands of every
# binary inside. Wheel filename tags are NOT trustworthy here: PyQt6 6.11.0
# ships a "macosx_10_14_universal2" tag whose binaries actually require 13.0.
#
#   Package        Pinned    Highest binary minos   Notes
#   -----------    -------   --------------------   ---------------------------
#   numpy          2.5.1     <= 12.0                latest release, no downgrade
#   scipy          1.18.0    <= 12.0                latest release, no downgrade
#   PyQt6          6.9.1     <= 12.0                6.10.0+ requires 13.0
#   PyQt6-Qt6      6.9.2     12.0                   6.10.2 / 6.11.1 require 13.0
#   Python         3.14      10.15                  no change needed
#
# Qt is the ONLY component that has to give ground: 6.9.2 instead of
# 6.10.2/6.11.1. numpy, scipy and Python all stay current. This is a much
# smaller sacrifice than the legacy environment, which additionally pinned
# Python 3.12, numpy 2.5.1 and scipy 1.18.0 behind an entire second venv.
#
# The media stack is already clear:
#   * IINA-derived Frameworks  -- all 72 dylibs verified <= 12.0 (both slices)
#   * libsingws_mpv_bridge     -- built with -mmacosx-version-min=12.0
#
# NOT YET VERIFIED: whether SingWS uses any Qt API introduced after 6.9. Pin
# these, rebuild, and run the suite before trusting this in a show.
#
# CRITICAL: pinning the VERSION is not enough. numpy and scipy publish several
# macOS wheels per version (macosx_10_15, macosx_14_0, ...), and a plain
# `pip install numpy==2.5.1` on a modern Mac silently picks the macosx_14_0
# build. The first real build with these pins still shipped 189 binaries
# requiring macOS 14. Install from a platform-pinned wheelhouse instead:
#
#   pip download --no-deps --only-binary=:all: \
#       --platform macosx_12_0_x86_64 --python-version 3.14 \
#       --dest wheelhouse12 -r constraints-macos12.txt
#   pip install --force-reinstall --no-deps --no-index \
#       --find-links wheelhouse12 numpy scipy
#
# build_singws_mac_intel.sh checks the finished bundle, so a wrong-variant
# install fails the build rather than shipping.
#
# Re-verify after any bump:
#   pip download --no-deps --only-binary=:all: \
#       --platform macosx_12_0_x86_64 --python-version 3.14 \
#       --dest /tmp/wheels -r constraints-macos12.txt
#   # then unzip each wheel and:
#   tools/verify_macos_min_version.py /tmp/wheels/<extracted> \
#       --arch x86_64 --maximum 12.0

numpy==2.5.1
scipy==1.18.0
PyQt6==6.9.1
PyQt6-Qt6==6.9.2
