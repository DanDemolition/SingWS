SingWS — First-Run Notes
========================

INSTALL
-------

1. Drag SingWS to the Applications folder.
2. Double-click “Open Me First” in this installer window.
3. Launch SingWS from Applications.

KARAFUN
-------

KaraFun songs play in KaraFun's own web player, inside a hidden browser that
belongs to SingWS. You do NOT need the KaraFun app, and SingWS needs no
Accessibility or Screen Recording permission for it.

The first time, SingWS downloads that browser once (about 200 MB), so the Mac
needs internet then. Open Settings > KaraFun, save your KaraFun email and
password (they are kept in the macOS Keychain, not in any file), and the player
signs itself in.

OTHER PERMISSION
----------------

• Location Services
  Choose Allow While Using the App when SingWS asks. This lets SingWS set the
  venue location used for request signups.

UPDATES
-------

Install later SingWS updates normally. Builds signed with the same SingWS
identity keep their permissions.
